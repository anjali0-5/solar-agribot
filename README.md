# Solar Agribot

## Overview
Solar Agribot is a solar-powered agricultural robot designed to assist with basic farming activities. The robot is designed to support operations such as seed sowing and water pumping.

## Objectives
- Reduce manual effort in basic agricultural activities
- Utilize solar energy as a renewable power source
- Develop a low-cost and practical agricultural robot
- Enable basic movement and agricultural operations

## Main Features
- Solar-powered operation
- Seed sowing mechanism
- Water pumping system
- Forward and backward movement
- Left and right movement

## Technologies and Components
- DC Motors
- Motor Driver
- Solar Panel
- Battery
- Water Pump
- Seed Sowing Mechanism
